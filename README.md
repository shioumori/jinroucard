# 夜明け前

スマートフォン向けの、ワンナイト人狼を土台にしたカードゲームの画面付き試作版です。

## 起動

`index.html` をブラウザーで開きます。追加パッケージは不要です。

## この試作版で確認できること

- 3〜8人の部屋設定と役職枚数の調整（役職総数は参加人数＋2）
- 役職確認、夜行動、カード配布、朝の会議、カード提出、最後の会議、投票、結果表示の画面遷移
- 大狼の追加（墓場の役職をすべて確認。役職確認時に人狼・大狼の仲間を表示）
- 救世主は参加者の過半数が提出したとき発動。シャドウは人狼・大狼・狂人が全員提出したとき発動
- 8種類のカードと、説明ガイド
- 次の試合で役職設定に戻る流れ
- スマートフォン幅に合わせたレイアウト

この版は1台の端末で進行を確認するためのフロントエンド・デモです。ロビーの他プレイヤーや他人の投票・カード提出はサンプルデータであり、部屋コードを使うオンライン通信はまだ接続されていません。実際に複数端末で遊ぶには、部屋状態を共有するリアルタイムのサーバーが必要です。

## ルールの仮置き

- 人狼を処刑できれば村人陣営、できなければ人狼陣営の勝利です。てるてるが処刑された場合は単独勝利を優先します。
- 複数人が最多票で同数の場合、その全員を処刑します。平和村がプレイヤーと同数ならプレイヤーを処刑します。
- 医者の能力は対象の現在の役職を村人に変更します。吸血鬼は対象または墓場の役職と交換します。
- 「過半数」は参加者数の半分を超える人数として扱います。
- 人狼・大狼が複数いる場合、人狼を対象にするカードはプレイヤー一覧で最初に見つかった人狼または大狼を対象にします。勝敗では、人狼・大狼が全員処刑された場合に村人陣営が勝ちます。
- 吸血鬼が役職交換後にどの陣営で勝利するか、医者が人狼を村人にした場合の勝利判定など、確定していない細則はコード上で今後調整が必要です。
